# CALIFICATED

Registro diario de alumnos (asistencia, tareas, etc.) y calificación ponderada. Funciona en el navegador, sin servidor y sin conexión.

**Usar en línea:** https://iqluismonreal-crypto.github.io/calificated/

- Los datos se guardan **solo en el navegador de cada persona** (localStorage); no se suben a ningún servidor.
- En el celular: abrir el enlace y elegir *Agregar a pantalla de inicio* / *Instalar app*.
- Por esa razón, los datos no se comparten entre dispositivos: respalda/exporta desde la propia app.
